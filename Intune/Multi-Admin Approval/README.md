Sends automated email notifications for multi-administrator approval workflow in Intune operations.

# DESCRIPTION
# This script manages and sends email notifications for a multi-admin approval process related to Intune actions.
# It informs relevant stakeholders about pending approvals, approvals granted, rejections, and completion status.
# The script ensures proper communication, tracking, and governance by notifying designated approvers and requestors
# at each stage of the workflow, supporting audit and compliance requirements.
